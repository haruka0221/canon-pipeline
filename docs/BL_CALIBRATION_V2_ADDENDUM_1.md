# BL 較正 v2 補遺 1：人間判定を LLM 一次判定＋人間監査に変更（2026-10-25）

プロトコル §5・§9 は「`r3_author` 真 300 / `r3` 真かつ `r3_author` 偽 100 / `r3` 偽 100 を人間が盲検判定」と定めた。
取得は完了し（`ba0e19a`）、解析済みレコード（15,261 件、`parsed_manifest_v1.json`）までは作ったが、
照合規則の適用と判定の抜き出しはまだ行っていない。この時点で、判定の方法を次のように変える。

1. 抜き出し方（500 件、3 層）は変えない。
2. 500 件すべてを LLM が一次判定する。指示文は判定前にコミットし、実際のモデル名を記録し、出力は直さずに保存する。
   判定の軸は二つ：「対象作品の版か」（VALID / INVALID / UNCERTAIN）と「刊本の関係」（v1 §7 の語彙）。
3. 人間は LLM の判定結果を見ずに、層別に抜いた一部（LLM VALID から 40、INVALID から 40、UNCERTAIN は全件、上限 40）を盲検で判定し、
   一致率を記録する。人間判定が最終判断であり、不一致は人間を採る。
4. 精度・網羅率の推定は、LLM 判定に人間監査の一致率を掛けた層化推定とし、OpenAlex R2+A1 の 800/150 監査と同じ扱いにする。
5. 成功基準（§9 最終項目：`r3_author` の精度 CI 下限 90%）は変えない。

理由：500 件を人間だけで判定する時間が取れない。v1（Q3 で 376 件を LLM 一次判定、78 件を人間確認）と
OpenAlex（LLM 1,147 件、人間 150 件）で同じ型を使っており、手続きとして確立している。
この変更は照合規則の適用結果・LLM 出力のいずれも見る前に記録した。
