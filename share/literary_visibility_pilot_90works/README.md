Provisional Literary Visibility Pilot Dataset

This file contains 90 works selected from the approximately 100 works
currently used as test cases from the doctoral reading-list appendix.

Eight known false Open Library work matches have been excluded pending
rematching. The selection-list metadata and matched-work metadata are
retained in separate columns because the source list and Open Library
occasionally differ in author spelling, title form, or publication year.

Indicators included:
- JSTOR Language & Literature title-based count
- provisional OpenAlex title + author count
- conservative OpenAlex literary-terms count
- Open Library edition count
- HathiTrust matched-volume count
- Wikidata QID where resolved

Important limitations:
- This is a provisional pilot dataset, not a formal release.
- JSTOR and OpenAlex counts are visibility indicators, not exhaustive
  counts of scholarship about each work.
- OpenAlex status and risk flags should remain attached to the values.
- Open Library record years may reflect edition-level metadata rather
  than the original publication year.
- Goodreads-derived values are not included because the source dataset
  has redistribution restrictions.
